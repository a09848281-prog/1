ℹ️ 制約とプライバシー

  • 位置情報は明示的な操作とブラウザの許可が必要です。
  • GPS座標はこの端末の画面に表示され、外部送信されません。
  • GitHub Pagesだけでは、複数端末のデータを管理者へ集約できません。必要な場合は、認証・アクセス制御を備えたバックエンドが必要です。
  • IPアドレスから正確なGPS位置を取得することはできません。

第三者の位置情報を取得する場合は、目的・保存期間・共有先を事前に説明し、本人の自由な同意を得てください。
