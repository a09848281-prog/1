# Consent Geo — 位置情報共有ツール

HTML・CSS・JavaScriptのみで動く、同意ベースの位置情報デモです。

## 公開方法
1. GitHub Pages を有効にします（Settings → Pages → Deploy from a branch → main / root）。
2. 公開された HTTPS URL を開きます。
3. 「位置情報の取得を許可する」を押し、説明を確認したうえでブラウザの許可を選びます。

## 機能
- スマホ対応の日本語UI
- 明示的な操作とブラウザ許可による位置情報取得
- 座標・精度・取得日時の表示、OpenStreetMapへのリンク
- 端末内記録、CSV書き出し、記録削除
- 案内リンク生成

## 大切な制約
- このアプリは取得した座標をサーバーに送信しません。記録はブラウザの localStorage 内にのみ保存されます。
- GitHub Pagesは静的ホスティングです。複数端末から管理者ダッシュボードへ記録を集約するには、認証・同意記録・保存期間・アクセス制御を設計したバックエンドが別途必要です。
- IPアドレスから正確なGPS位置を取得することはできません。
- 位置情報を扱う前に目的、共有先、保存期間を本人に説明し、明示的な同意を得てください。

このプロジェクトは ActiveTK/Tokutei のコードを複製したものではなく、HTML/CSS/JavaScriptのみで作った独立した簡易実装です。
